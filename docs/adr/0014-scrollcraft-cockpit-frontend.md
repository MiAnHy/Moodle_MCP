# 0014. ScrollCraft Cockpit Frontend and Interactive Dual-Transport Inspector

We decided to adopt the **Instrument / Cockpit Grammar** from the ScrollCraft specification to author a zero-dependency, high-contrast, scroll-driven web interface showcasing the Moodle AI Platform, integrating dimensional hero layering, an engineered Two-Phase Mutation emotional peak, and a live Dual-Transport Protocol Inspector.

## Context & Rationale
1. **Generic Template Drift**:
   Conventional AI and SaaS marketing pages suffer from generic template drift: passive diorama 3D assets, ungrounded statistics, and superficial animations that fail to communicate deep protocol-level security and mechanics.
2. **Protocol Opacity**:
   The Universal Moodle MCP Server operates under sophisticated architectural invariants (Two-Phase Mutation, SSRF/DNS-rebinding prevention, session-scoped token isolation, and semantic pruning). A static text document or passive video fails to give developers and academic administrators tactile conviction in these safety guarantees.
3. **Deployment Friction**:
   Prospective users need immediate, interactive comprehension of the dual transport mechanisms (local Stdio vs multi-tenant SSE) and instant client configuration recipes (Claude Desktop, Cursor).

## Decision
1. **Structural Grammar & Palette (`web/` & `web/css/theme.css`)**:
   - Adopt the **Instrument / Cockpit Grammar** (`uniqueness.md §2.4`), rejecting passive filmic one-shot templates.
   - Establish a **Cybernetic Academic / Digital Blueprint** design floor: ultra-dark navy canvas (`#07090e`), slate typography (`#f8fafc`, `#94a3b8`), and technical cobalt/cyan accents (`#38bdf8`, `#2563eb`).
   - Forbid fake stat counters, ungrounded clay dioramas, scroll arrows, and visible em dashes.
2. **Dimensional Layered Hero (`web/assets/`, `web/index.html`)**:
   - Implement three physically distinct visual planes:
     - **Background Plane ($Z = -180\text{px}$)**: Isometric architectural university campus blueprint (`campus-blueprint.svg`).
     - **Midground Plane ($Z = 0$, Anchor)**: Frosted glass Moodle protocol gateway badge (`protocol-gateway.svg`).
     - **Foreground Plane ($Z = +80\text{px}$)**: High-contrast telemetry chip streaming verified MCP session initialization data.
3. **Engineered Emotional Peak & Signature Move (`web/js/inspector.js`)**:
   - **Act 4 Peak (Two-Phase Mutation Latch)**: An interactive simulator where an autonomous grade submission is intercepted by the safety latch (`dry_run: true`, `PENDING_HUMAN_CONFIRMATION`), demonstrating preview diffing before human confirmation commits the transaction.
   - **Act 6 Signature Move (Dual-Transport Inspector)**: An interactive protocol toggle comparing Stdio (process stdin/stdout with SSRF protection) and SSE (multi-tenant HTTP with session-scoped isolation), accompanied by a one-click terminal connection command.
4. **Static Engine Integration (`src/transport/sse-engine.ts`)**:
   - Mount static file serving inside the Express SSE engine, allowing the standalone Moodle MCP server binary to serve the verified web cockpit directly on HTTP port 3000/4500 when requested.
5. **Headless Verification Protocol**:
   - Validate desktop (1440x900), mobile (390x844), and reduced-motion states via Playwright (`shoot.mjs`), confirming zero dead scroll, WCAG AA contrast compliance, and full cue settlement.
